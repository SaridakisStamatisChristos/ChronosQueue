# Failure / repair ledger

1. **Chat execution interruption during initialization** — reproduced by repository history: only `.gitignore` and README landed. Classified as orchestration/UI interruption, not a queue-code defect. Repair: resumed on isolated `r7-zero-to-hero` branch from the last real commit.
2. **Delay scheduling CLI contract mismatch found during self-review** — initial local CLI draft rejected `--delay-ms` despite product requirements. Repair: server now derives delayed schedule time from its own clock and CLI sends `delay_ms`; absolute and delayed forms are mutually exclusive.

Further defects found by executed tests are appended before final merge.
3. **Batch-requeue regression syntax failure during falsification expansion** — full suite failed to import `tests/test_core.py` due to a mismatched bracket in newly added test code. Classified as test-harness defect. Repair: corrected syntax, retained the regression, and reran the full verification suite.
4. **Fresh-venv package installation contract failure** — `pip install --no-build-isolation .` failed because a pristine venv did not contain the declared setuptools backend. Classified as packaging/documentation defect. Repair: normal installation now uses standard build isolation (`pip install .`); Docker no longer depends on packaging/build downloads and runs the stdlib-only source tree directly via `PYTHONPATH`.
5. **Real-process stale lease during smoke harness** — a 1-second test lease expired while multiple fresh Python CLI processes started. Classified as harness timing defect, not queue logic. Repair: real-process/CI smoke uses a 30-second lease; deterministic lease-boundary correctness remains covered by fake-clock tests.
6. **Docker reachability defect found in pre-CI audit** — Docker inherited the host-safe `127.0.0.1` listen default, which would make a published container port unreachable. Classified as deployment defect. Repair: container command explicitly listens on `0.0.0.0` inside the container while Compose publishes only `127.0.0.1:8080` on the host.
7. **Unsafe malformed-input/storage error surface found in audit** — raw conversion errors could become 500s and storage errors could expose backend details. Repair: malformed value/type/key errors map to generic 422 responses; storage-unavailable responses are generic 503s.
8. **Provisional license assumption removed** — a local draft had selected Apache-2.0 without an explicit product decision. Classified as packaging/governance overreach. Repair: removed the license grant and marked licensing as a commercial-readiness decision.
9. **Input/schema hardening findings** — string values could masquerade as queue/tag arrays; lease CHECK allowed partially populated metadata; timestamp conversion used avoidable float arithmetic. Repair: strict array/type checks, stronger SQLite CHECK constraints, and integer-only datetime conversion with regression tests.
